    / 22 · Technical notes
    Technical notes.
    Concise engineering notes.
    NOTE / 01
    Reversible Windows changes
    Document the starting state, choose supported settings, and verify rollback before applying broad changes.
    NOTE / 02
    CI/CD for small teams
    Keep lint, tests and release builds independent. Publish artifacts only after checks and verify version alignment.
    NOTE / 03
    Performance measurement
    Change one factor at a time, record the environment, repeat the benchmark and report variance.
