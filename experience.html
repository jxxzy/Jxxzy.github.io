MR.4NONY / LIBRARY

Technical library.

Safe rollback in Windows utilities

Capture original state, preview settings, request approval, read back applied changes and detect drift before restoring. Reversible actions and evidence are preferable to blanket promises.

Read note ↗

A verifiable Android release

Keep CI checks separate from signing and release. Align SemVer, tag and artifact version; publish checksums and retain traceable source revision.

Read note ↗

Measure before optimizing

Record hardware, OS and workload; change one factor at a time and repeat runs. Report variation and limitations, not a single best benchmark.

Offline static websites

Cache only safe same-origin core assets. Use network-first navigation and avoid caching personal data or external API responses.
