Privacy

This is a static portfolio hosted by GitHub Pages. No site-operated analytics, advertising tracker or contact-form database is included.

Preferences

Language, theme, motion settings and saved project identifiers are stored locally in your browser. Clear your site data to reset them.

Contact and GitHub

The contact form prepares an email in your own email app; it does not submit information to a website server. Public GitHub statistics, repository listings and public events are requested only when you press the corresponding load button. Toolbox inputs and selected files are processed locally in the browser; no files are uploaded. The profile photo is loaded from GitHub's avatar CDN. External links and GitHub hosting are subject to their own privacy policies.
